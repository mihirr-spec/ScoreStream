How it works

Four steps, one winner.

The whole event, exactly as it runs in ScoreStream.

01

Set up the event

The admin creates the event, sets a weighted rubric, and adds teams and judges. Everyone gets a private code.

02

Judges rate with stars

Judges tap the stars for each criterion and add a comment. The weighted total out of 10 is done for them.

03

Ranks update live

MongoDB notices every new score and re-ranks the teams. Every open screen updates in under a second.

04

AI writes the feedback

When the event closes, AI reads every judge comment and writes each team a summary, strengths and next steps.
