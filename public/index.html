How it works

From first score to final feedback in four steps

No spreadsheets, no adding up marks by hand, no waiting for results.

1

Set up the event

The admin creates an event, defines a weighted rubric, and adds teams and judges. Everyone gets a private access code.

2

Judges score

Judges log in, rate each criterion with stars and leave a comment. The weighted total out of 10 is calculated automatically.

3

Ranks update live

MongoDB notices every new score and re-ranks the teams. Every open leaderboard updates in under a second.

4

AI writes feedback

When the event closes, AI reads all judge comments for each team and writes a summary, strengths and improvements.

Under the hood

MongoDB does the heavy lifting

The rules, the maths and the live updates all live in the database itself.

$jsonSchema

Validated documents

Every collection has a schema validator, so the database rejects badly shaped data.

unique index

One score per judge

A unique index on event, team and judge makes double scoring impossible.

$setWindowFields

Ranking in the database

An aggregation pipeline averages scores, joins team names, ranks teams and saves the result with $merge.

watch()

Change Streams

MongoDB pushes every new score to the server the moment it is written. No polling.

text/event-stream

Live in every browser

Server-Sent Events carry each new ranking to every open screen instantly.

explain()

Proven fast

Indexes turn full collection scans into index scans that read only what is needed.
